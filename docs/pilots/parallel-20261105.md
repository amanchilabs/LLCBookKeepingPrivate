STORY-BOOK-001: define one versioned bookkeeping-to-tax exchange contract with
synthetic fixture, validation and serializer tests. Preserve journal calculations,
accounting policies, authentication, security and persistence. The contract carries
already computed cash-basis book income, expenses and net income, period, USD,
source business/reference, explicit unreviewed status and limitations. Serialize
bigint cents losslessly as strings. Validate unknown versions, malformed dates,
period ordering, unsupported currency, nonintegral amounts and missing source.
Never claim tax classification, deductibility, tax basis, tax liability or direct
compatibility with return software. No database changes or ledger mutation.

STORY-BOOK-002: connect an explicit export preview and user-controlled JSON share
action in Reports using existing cash-basis report values. Display period/basis,
source, review-needed state and exclusions; block stale/mismatched or invalid
periods and failed report loads, handle share errors and cancellation accurately.
No automatic sync or mirrored editable ledger. Preserve all existing reports and
CSV/PDF exports. Unit/regression/type checks plus native simulator flow evidence
are required; never substitute static assertions for native acceptance. The user
controls whether the system share sheet sends the file outside the device.
